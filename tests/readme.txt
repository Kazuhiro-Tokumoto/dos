MYDOS - an MS-DOS compatible disk operating system

This floppy contains:
  IO.SYS       the DOS kernel (INT 21h, FAT12, MCB memory manager,
               .COM and .EXE loaders)
  COMMAND.COM  the command interpreter
  HELLO.COM    a minimal .COM program
  HELLO.EXE    an .EXE that checks its own relocations were applied
  DOSTEST.COM  the INT 21h test suite
  AUTOEXEC.BAT run at startup by COMMAND.COM

Try: DIR, VER, MEM, TYPE README.TXT, HELLO, HELLO.EXE, DOSTEST
